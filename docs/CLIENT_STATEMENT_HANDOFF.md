# 已发布账单的客户交接

沿用001–036，无新增SQL、权限或查询。在原月结工作台的已发布账户卡片中显示。

- 按正式账单ID匹配现有查阅汇总，区分已有确认、尚无确认、信息不完整。确认人数和最近确认时间只表示提交过确认的客户，不代表全部成员或费用认可。
- 汇总截断、重复ID、缺失记录或确认次数/时间矛盾均显示未知；主流程总览使用相同判断，避免重复记录被算作全部已阅。
- 只为已发布卡片生成对应账单的客户链接。链接仅有账单ID及定位锚点，不附加内部汇率、采购利润、联系人或权限令牌。
- 客户链接指向当前部署域名。请客户先登录、再打开链接；现有登录页不会保留账单查询参数。成员与财务授权仍由原数据库检查，内部员工不能代确认。
- 点击复制只调用浏览器剪贴板，不调用API、不发送短信/邮件、不更改已阅状态。剪贴板不可用时选中只读文本供手动复制。页面不把复制当作已通知或已交付。
- 客户权限核查继续用原管理员CRM入口，账单问题继续用原工单；本项不自动开通权限或操作余额。

验证：27项交接组件、月结页面、主流程、客户账单页和查阅API测试通过；类型检查及构建通过。组件交互测试覆盖复制、拒绝剪贴板后的手动选择、不发API请求和不产生查阅确认。Chromium用明确虚构静态示例检查375/1440布局并检查手机截图；真实客户端路径在中英文下仍跳转登录。没有实际登录客户查看或发送任何链接，真实Preview仍须授权账号验收。
