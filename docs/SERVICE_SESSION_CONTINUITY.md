# 账单工单的会话与语言衔接

沿用001–036，无新增SQL或业务API写入。

- 客户打开服务工单但未登录时，保留已验证的ticket及关联statement，验证后回到原工单详情锚点。
- 工单页面切换中英文时保留所选工单和账单筛选。工单列表、客户提问成功链接直接定位原详情；财务端沿用自己的企业/月筛选。
- 客户回复收到401时，原表单只导航到客户登录并保留原工单位置。回复正文不进入URL、不跨登录保存，也不在登录后自动补发；客户应核查原记录后重新输入。
- 客户提问或确认已阅收到401时，返回原账单，而非新建工单或自动确认。请求失败不显示已提交/已阅。
- 共享表单的员工登录处理保持原路径，默认客户表单无目标时仍用原默认入口。其他客户权限、工单匹配和账单筛选仍由原数据库与RLS检查。

返回地址只新增客户account/service分支，参数只接受ticket、statement的UUID及匹配的详情锚点；外站、后台、未知/重复参数和无效ID被拒绝。原clientStatementReturnTo仍只接受账单页，通用登录使用受限clientReturnTo。隐藏Preview测试入口不公开链接，原环境/身份/CAPTCHA门禁保持。

验证：57项回跳/客户界面/服务页测试及22项财务工单/共享表单超时/认证API回归通过，类型检查与Next.js构建通过。两个浏览器脚本共14项检查通过，375/1440布局无横向溢出，手机截图已检查；没有发出业务或认证API请求。成功登录与401回复回跳用模拟响应验证，未登录真实客户、发送短信或发布工单回复。真实Preview仍需授权身份验收。
