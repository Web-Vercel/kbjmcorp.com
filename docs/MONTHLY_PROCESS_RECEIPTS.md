# 月结制单、独立复核与正式发布操作确认

2026-11-10（温哥华）。本批集中处理月结三项关键操作，沿用001–037，不新增SQL或审批步骤。

## 办理变化

1. 制单回执须包含原草稿、来源快照及报价ID，均与本次选择一致。登记成功只确认草稿记录，不把同内容重试返回的旧草稿说成当前仍待复核。
2. 独立复核回执须匹配原草稿和所选通过/退回决定，避免把相反决定或其他草稿的响应展示为成功。制单、复核本身仍不发布或扣款。
3. 正式发布回执使用服务器读取的企业、月份及原草稿，浏览器逐项核对后显示正式账单编号。保留现有服务器报价重算、数据库原子发布、余额检查及防重复记账规则；客户端不提供或推算扣款依据。
4. 成功后不自动刷新清除回执。核查入口在新页定位本企业、本月份的原草稿或正式账单，不以重新打开页面触发写入。
5. 超时或响应不完整保留原输入，不自动重试。会话过期也不直接跳转丢失说明，提示重新登录后核查原记录。同一草稿重试仍受原数据库保护；回执不是新增扣款或银行汇款证明。

列表为加载时状态，最终状态以重新查询原记录为准。发布资金预览不预留余额，真正发布仍在数据库事务中重新核验。
