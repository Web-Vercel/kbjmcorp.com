# 制单与独立复核提交回执

沿用001–036，无新增SQL。数据库已返回制单UUID；原API丢弃该编号，本项将其作为经过格式检查的草稿回执返回。

- 制单成功显示草稿编号、等待另一账号独立复核的说明，以及带企业/月筛选的原草稿定位链接。
- 复核成功返回原草稿编号，明确本次通过或退回；原记录页面展示后续状态。
- 没有有效UUID或复核回执与原草稿不一致时，页面不显示成功；保留原输入并提供刷新/查看原记录入口。
- 请求30秒超时后终止等待，提示结果待核查，而非推断数据库没有保存。不会自动重发。
- 同次等待中拦截重复点击；原样重试继续使用原数据库制单/复核的幂等保护。内容改变可能冲突，必须核查原记录。
- 明确的权限、MFA、冲突、来源与金额问题继续分别提示。API仍使用原同源、员工身份与数据库权限检查；回执不触发发布、余额扣减或通知外发。
- 通用AdminForm未修改；只替换月度制单和独立复核两个入口。

验证仅使用虚构数据：API回执、空回执、跨草稿回执、并发点击、30秒超时、原样重试、登录过期、退回与隐私错误提示。真实Preview中的账号办理仍需获授权人员验收。

验证结果：23项相关API、提交表单及结算页面测试通过，另有6项隔离数据库主流程测试通过；类型检查和Next.js构建通过。Chromium确认中英文结算页跳转员工登录，跨来源API返回403。本地认证配置未启用，同源API实际返回503 unavailable且无回执，不能将其算作正常认证链验收；认证与MFA分支由模拟API测试覆盖。没有使用真实账号执行财务操作。
