保存期间锁定试算输入和重新试算操作，并用同步锁阻止重复保存。返回编号必须是有效UUID，API和前端均检查；缺失/畸形回执不当作已保存。成功回执继续提供该企业该月的报价历史和月结工作台链接，报价不等于客户接受，也不触发扣款。

保存有30秒上限；网络、5xx或回执异常时保留原试算与请求编号，暂锁定修改，原样重试发送相同负载，继续使用原save_agency_quote_revision的重复提交保护。提示先核查历史，不因未知结果重新试算另存。若已核对历史并确需修订，显式解除锁定后可继续修改；原记录不被改写。

过期登录、员工二次验证、权限不足、原请求冲突及参考汇率变化分别说明。参考汇率变更时不暗中换价保存，仍需核查历史并重新获取/试算。已知错误保留输入。历史链接不发送通知、不授权，不宣称未完成的请求一定没有保存。
