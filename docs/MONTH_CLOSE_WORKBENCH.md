# 月结工作台

入口：`/zh/operations/month-close`。按客户企业、广告账户、自然月查询闭环进度。

现有项目依次执行过 001–026 后，在 Supabase SQL Editor 新建「23 月结工作台与按月流程导航」，执行 `supabase/migrations/027_month_close_workbench.sql`。此脚本只增加受控只读查询及按月查询重载，不创建客户、资金、账单或 API 来源。新隔离项目才使用重新生成的 bootstrap；现有项目不要运行 bootstrap。

工作台区分：整月未读取、未交接、活动覆盖待核实、依据待独立复核、缺少匹配报价、待制单、待独立复核、缺少资金账户、余额不足、待管理员正式发布、已发布并记账。七日或跨月来源明确提示不能替代选定自然月。

流程链接携带企业和月份；报价入口还携带账户关联编号，只预填已核实广告成本，不自动生成收费约定或汇率。API 读取入口携带预期广告账户，服务器配置不匹配时拒绝读取。进入页面不触发任何业务写入。

来源、覆盖核实、报价、结算及发布回执按月份在数据库限量前过滤，避免最近版本遮挡历史月份。未交接来源仅显示存在状态，不暴露来源编号或原文。报价私有汇率及费用明细不出现在工作台接口。

独立复核不能由原制单账号执行，管理员亦不能通过工作台绕过。待核对到账不计入余额；工作台不预留资金，正式发布事务再次检查余额。指定虚构企业的到账验收模式不能被用来登记其他企业的真实资金。

工作台展示已发布回执；客户仍须使用其获授权账号查看月度结算账单。暂停来源交接不删除历史账单。此轮不增加定时同步、实际银行转账、退款或账单更正。

验证：数据库测试覆盖完整阶段推进、旧月份限量前过滤、查询无写入、权限和私有信息隔离；UI 测试验证确认勾选和广告账户锁定；流程动作测试验证角色及禁止自复核。
