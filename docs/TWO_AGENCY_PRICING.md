# 双公司收费：独立计价与核算基础

入口：内部运营中心“ 双层收费草稿与试算 ” → `/zh/operations/pricing`。仅管理员及中国财务职责读取，只有管理员可以新增收费规则草稿；仍要求既有 MFA。公开首页与客户报价不变。

## 数据库

独立测试库执行 `supabase/migrations/016_agency_fee_drafts.sql` 一次，建议保存“12 双公司收费规则草稿—已执行”。只新增规则草稿表及保存函数，不改现有余额、报告、已入账流水或旧费用算法。已有月度对账015须按其说明另行安装，不重跑初始化。

规则按客户、公司分别记录币种和递增版本。加拿大固定CAD、中国固定CNY，拟生效月份只是草稿意图，不构成实际生效。草稿不可修改或删除，修改意向通过新版本表达，并保留管理员审计。普通客户、加拿大投放执行及普通客服不自动获得内部成本报价权限。

## 计价

每层可选择比例、固定月费、比例与最低月费取较高者。最低月费不是额外加收。比例默认为0；未约定时不默认10%。零基数是否免收单独配置。百分比最多两位小数，0–100%，金额最多两位小数；CAD/CNY汇率最多8位小数。所有钱款用整数分与HALF_UP计算，不用浮点数算金额。

加拿大基数为平台CAD原始广告费；中国基数须显式选择仅人民币广告成本，或含加拿大服务费的上游采购总额。先将CAD上游总额整体换算一次，再把广告成本换算和加拿大服务费换算的舍入尾差分配到加拿大服务费，保证拆分相加等于应付上游总额。试算不自动取得真实汇率。

例：CAD1000广告费 + CAD100加拿大执行费，5.20汇率 → 上游采购成本CNY5720；中国固定服务费CNY580 → 客户结算试算CNY6300。服务费为收入组成，不能称为净利润；两公司的员工、系统、银行、税费等成本尚未扣除。

## 界限与后续

试算只在浏览器内进行，刷新清空；不会保存报价、建立应收应付或扣客户余额。保存规则草稿是独立操作，不能把试算显示当作已保存或已被客户接受。计算器还未自动加载持久化草稿，不声称已经形成正式规则应用流程。

后续必须增加双方确认依据、独立复核、正式生效版本、来源报告对应、汇率凭证及人民币结算快照。正式账单固定引用当时的规则版本；调价不改历史账单。原始广告报告不包含代理加价，中文报告忠实保留平台数字，商业服务费用另列。

公司间结算需有独立应付及付款记录，不能因为中国向加拿大付款就再次扣客户钱包。客户预付款不是两家公司的营业收入直接相加；收入确认、关联交易定价、税务和跨境支付凭证需由两地会计确认。本轮未实现公司间付款、报告发布、自动收费或利润报表。
