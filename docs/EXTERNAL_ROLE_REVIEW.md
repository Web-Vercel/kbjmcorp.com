# 代理与客户体验及权限检查

日期：2026-11-15。Preview 检查，不代表 Production 已发布，也不代替托管环境的实际账号验收。

## 角色边界

| 功能 | 广告客户 | 外部代理 |
| --- | --- | --- |
| 登录及账号安全 | 邮箱密码，不强制验证器；可到邮件恢复入口重设密码 | 同左；账号需管理员启用 |
| 企业与客户 | 自己获授权企业 | 已确认归属客户；可提交引荐，不能自行确认归属 |
| 资金、账单、分析 | 本企业授权范围，含账单下载、资金记录及分析 | 不提供客户余额、内部广告成本和客户账单权限 |
| 佣金及结算 | 不提供代理明细 | 自己的规则、佣金、等待期、结算及已核实付款记录、CSV |
| 合作文件 | 不开放代理私密文件 | 自己的合作文件、引荐及归属依据；管理员按授权查看 |
| 客户服务沟通 | 提交本企业问题、查看回复和导出沟通记录 | 本轮不新增代理客服渠道，不能借用客户工单权限 |
| 余额退款 | 可按已登记约定申请及查看进度，不能自行批准或改余额 | 不代客户申请；相关佣金暂停或调整以核实业务为准 |
| 审核及付款 | 均无内部审批、记账或付款核实权 | 同左 |

当前仍为人工收付款。付款通知不增加余额；批准不等于已付款；不得把真实银行交易或已结算业务历史直接改写。

## 本轮体验改进

- 客户首页提供账单、资金、服务沟通的快捷入口；合作阶段使用通俗文字，线下付款登记默认收起，编号按需展开。
- 客户服务页使用独立客户授权，不要求额外的旧成员关联；返回客户总览，避免绕回旧页面。
- 代理首页显示下一步入口及本次加载记录数量，不把列表数量当作全量统计。
- 代理结算空白页提供佣金等待期的查询入口；无文件或引荐时明确说明下一步。
- 账号安全提供邮件重设密码入口；代理保留菜单和退出，正常使用不要求验证器。
- 管理员切换代理上传文件时，清空先前代理的引荐及归属选择；服务端仍独立核查，不能用前端选择代替权限。
- 代理数据读取失败时保留菜单和退出，未知金额不显示为零。

名称、金额、日期使用蓝色；说明及普通状态为中性灰色。测试标识、付款未知结果及重要错误保留可见。
