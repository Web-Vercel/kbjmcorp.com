# 月度资金对账（015）

在隔离测试 Supabase SQL Editor 整份执行 `supabase/migrations/015_ops_monthly_cash.sql` 一次，建议保存“11 月度资金对账只读查询—已执行”。不重跑初始化，函数只读，不扣费、不修改余额、不代替银行对账。新 Preview 页面按公司和月份调用该函数。

统计基于钱包流水 posted_at，使用 Asia/Shanghai 的月份起止，起点包含、下月起点不包含。月初余额为起点前全部流水，月末余额为下月起点前全部已入账流水；当前月为截至查询时已记录的数据，不是最终关账。不按广告报告月份追溯改写流水入账日期，历史月份不是不可变的已签发结算单。

充值为正数，广告费、服务费和退款支出按正数支出显示；调整保留有符号净额。所有汇总在数据库用精确整数／numeric计算，并以十进制字符串返回。每个币种单独对账，不能合并不同币种金额。页面检查资金等式，异常时提示核查，不给出正常结算展示。

没有费用入账不代表没有平台费用，未发布报告不视为零消费。本功能不是OpenAI来源报告，不声称平台API或银行接口已连接。它不自动冲正、退款、锁账或扣款。

权限沿用 finance.read、对应企业范围与 MFA；客户不能调用这个内部查询。无效月份、非每月1日、未来月份、2000年前月份均拒绝。若函数尚未安装或查询失败，显示不可用，不将未知值显示为0。

验收：专用虚构钱包当月充值1000.01且无其他已入账记录时，月初0、充值1000.01、月末1000.01、流水1笔；其他月及真实钱包依其实际已入账记录显示，不人为填充值。客户侧月报及正式来源发布扣费流程仍待后续开发。
