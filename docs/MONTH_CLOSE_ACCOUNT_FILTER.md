# 月结账户办理列表筛选

沿用001–037，无新增SQL或审批，仅在Preview内部月结工作台使用。账户列表新增全部、本账号可处理、等待其他角色、条件待确认、已发布五种视图，数量来自当前账号原有角色待办分类，独立复核和收款配置限制保持。

URL使用list参数，可保存同一企业和月份的筛选。切换企业/月默认回到全部。筛选只作用于下方账户卡片：资金合计、主流程、客户查阅、公司间核销及CSV办理清单均使用原整月完整数据，不因隐藏卡片而减少核算范围。筛选为空明确提示不能推断无费用。

顶部待办仍覆盖全部账户；在筛选视图中点击待办链接，会回到该企业、该月全部账户并定位对应卡片，避免隐藏的目标无法定位。默认全部视图保留原页内定位。未知筛选参数返回404，不默认为无账户。只有通过月结数据核对后显示列表筛选，原权限及数据库动作均保持。

验证：27项页面、角色待办、进度校验与主流程测试；包括两账户仅一账户匹配时仍显示完整月结发布数量和资金。四项隔离Chromium用例验证中英文、手机/桌面、表单保留企业/月及列表状态，使用虚构账户。TypeScript及Next构建通过。未修改真实客户数据或发布Production。
