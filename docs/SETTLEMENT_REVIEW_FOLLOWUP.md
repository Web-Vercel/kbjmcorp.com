# 结算复核后的下一步

沿用001–036，无新增SQL、查询或财务操作。在原结算草稿卡片内，根据该条记录及当前账号给出下一步。

- 待复核：本人制单继续要求另一账号独立复核；有复核权限时提示使用原复核表单。
- 退回或报价已归档：管理员直接载入该草稿引用的报价，在其原企业和月份另存新版本。非管理员只能查看本月报价并请管理员修订。原草稿及复核记录不改写。
- 已通过、未发布且报价未归档：管理员链接到本草稿发布核对区域。财务账号仅提示交由管理员办理，不显示发布入口。
- 已有正式账单：不显示报价修订或再次发布入口，转到原月份月结工作台及公司间到账核对。已发布不代表客户已阅或公司间已结清。
- 未知复核状态：提示刷新核查，不假定通过。

所有链接使用该条草稿自己的企业、月份及版本编号；空月份跨月列表也不使用其他记录的月份。既有服务端权限、余额核验、独立复核与重复结算拦截继续生效，点击下一步不执行写入。
