# 资金摘要更新 014

在隔离测试数据库 SQL Editor 整份执行 `supabase/migrations/014_ops_cash_summary.sql` 一次。只增加只读函数；不创建用户、不改变授权、余额或流水。不要重跑初始数据库脚本。保存名建议“10 资金摘要只读查询更新—已执行”。

新 Preview 的 `/zh/operations` 选择企业并查看摘要：分别显示客户付款通知的待核对笔数金额、到账制单的待独立复核笔数金额，以及最近10条已入账流水。余额来自全部流水汇总；统计与最近流水在同一只读数据库快照中生成，最近列表不用于计算总余额。

付款通知和到账制单可能对应同一次付款，不可相加当作充值。制单未批准时不计余额；拒绝不计入待复核。新函数仍要求 finance.read 权限及原有 MFA，普通客户不能调用内部摘要。金额和计数采用十进制文本返回，避免大整数 JSON 精度损失。

数据库未更新或查询失败时显示不可用，不假装待复核为零。最近流水不是完整对账导出。界面会保留所选企业，避免刷新后下拉框与摘要企业不一致。
