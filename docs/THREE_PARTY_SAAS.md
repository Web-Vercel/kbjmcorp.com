# 三方运营与客户服务（开发版）

依据用户提供的手绘业务分工设计。图中平台自动生成月度 PDF、接口能力等属于待核实业务设想，不能作为已验证的技术能力。照片没有收入仓库或公开网站。

## 职责与访问范围

| 主体／职责 | 可操作 | 不开放 |
| --- | --- | --- |
| 加拿大 KBJM 投放执行 | 客户与广告账户归属记录、原币月度来源登记、补正新版本 | 客户人民币钱包、服务费草稿、联系人、合同和客服工单 |
| 中国智点未来客服 | 企业 CRM、联系人、明确授权、合同协调、一般服务工单 | 原始报表交接包及财务核对草稿、财务工单 |
| 中国财务制单 | 钱包与报价只读、合同只读、来源核对、人民币费用草稿、财务工单 | 自动支付、审核自己制作的草稿 |
| 中国财务复核 | 独立批准或退回核对草稿、财务工单 | 将自己的制单直接审核通过、自动扣款 |
| 企业客户 | 已授权公司内的服务账户、已发布中文月报、余额与充值申请、服务工单 | 其他客户、内部交接、复核备注；无财务授权的成员也不可访问财务工单 |

平台所有者保留全局管理和职责分配，但同一人不能自审财务草稿，即便同时拥有两个财务职责。员工使用独立的密码及 MFA；客户使用已验证手机号和明确公司授权。邀请、联系人记录和角色名称本身不构成客户访问授权。

这里是单一代理平台内两个固定运营单位的职责模型，不是通用多代理商 SaaS 租赁平台。单位名称不是已核实的法人、签约方、收款方、纳税主体或数据库所在地；上线须用真实法律资料确定这些关系。技术权限也不代替跨境资料处理的合法依据。

## 报告交接

1. 加拿大执行人员登记广告账户与月度来源：原币金额、期间、原始报告时区、语言、来源编号及可选文件 SHA256。账户只显示未验证归属，不伪造平台连接成功。不限制为图中的十个客户。
2. 原件目前只登记元数据；系统没有下载、读取或验证平台文件，也未证实平台会自动生成中文／英文 PDF 或提供可接入 API。接口预留不代表真实连接。
3. 中国制单人员使用当天北京时间有效的真实 CAD/CNY 锁定报价核对草稿，整数最小货币单位和 HALF_UP 舍入。默认未约定服务费为零；额外收费须有协议依据，不自动收取 10%。USD 原件可以登记，但不能冒充 CAD 计算。
4. 另一位获授权人员独立复核。失效／演示报价、旧来源版本、自审均拦截。补正创建新版本并使旧的待复核草稿失效，保留记录。
5. 复核完成状态为“待发布”。本次没有接通正式发布服务，不会创建客户月报、扣钱包或执行转账。未来发布服务仍须验证原件、最新版、已批准金额、中文整理版本、幂等及资金记账事务。

客户预存余额、平台实际广告费用和两家公司间结算是不同业务记录，不应相互冒充。本次不增加公司间真实划款、银行收款、发票或收入确认。

## 服务工单与容量

客户可针对已授权公司提交账户、报告、财务或其他问题。一般工单进入中国客服队列，财务工单只进入中国财务队列；加拿大执行人员不可见。服务回复由 SQL 识别真实角色，客户不能伪造员工回复或已解决状态；客户回复已解决工单会重新打开。审计不复制私密消息正文。补正意见不应包含联系人或私有定价。

开发版保护上限：每公司同时最多 20 个未解决工单，每工单 200 条消息；工作台查询最近 100 条记录，来源最多 100 个版本，账户选择最多 500 条。更大规模应增加分页、搜索、文件存储和支持 SLA，不能把列表截断误认为完整财务总账。
