# 工单沟通记录下载

沿用001–037，无新增SQL或审批。已打开的客户服务工单、员工服务工单及账单问题详情中，均提供“下载本工单沟通记录（CSV）”。

文件含工单编号、标题、类别、下载时状态、创建/更新时间、关联账单和结算月份、消息条数，以及逐条消息的编号、时间、发送方和内容。所有时间保留ISO 8601时区。文件带UTF-8 BOM、CSV转义及公式前缀防护；不包含人员身份ID、内部回复请求键、摘要、原始上游成本或密钥。

下载为GET只读请求，服务器重新使用当前会话读取，沿用请求及消息RLS；财务权限、企业隔离和员工二次验证均由原权限函数决定。不使用service-role。没有权限和不存在均返回404；会话过期返回401；消息为空、超过200条、重复或跨工单数据不会生成文件。读取前后校验工单资料，发生变化返回409要求刷新；文件是下载时副本，未来不自动更新，不代表最终收费认可或财务调整。

界面有并发点击保护及30秒超时。成功提示仅表示已请求浏览器下载，不声称文件已经由用户保存或阅读。不会发送回复、标记已阅、改变工单状态或资金。

验证：27项导出/API/回复/会话组件测试；7项隔离PGlite数据库测试，包括新增SELECT权限用例，验证跨企业、员工缺少二次验证及撤销财务授权后均看不到工单和消息。未下载真实客户沟通内容。

浏览器补充：使用实际下载组件及虚构CSV接口响应，在本地Chromium完成中英文×375/1440宽度四种用例，核对下载文件名和内容、409更新提示及页面无横向溢出。仅为隔离组件浏览器验证，不代表真实客户线上下载验收。TypeScript检查与Next.js构建通过。
