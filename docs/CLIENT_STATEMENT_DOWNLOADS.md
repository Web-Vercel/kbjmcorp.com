# 客户月度结算账单下载

入口：`/zh/account/statements`（英文 `/en/account/statements`）。仅通过原有 `get_client_monthly_statements` 查询，依照客户的企业成员关联与财务权限返回已发布账单。无员工或管理员绕过客户授权的查询路径。

每份正式账单提供 CSV 和阅读版 HTML。CSV 带 UTF-8 BOM、引用和公式注入防护，可用 Excel 打开。阅读版不加载外部资源或脚本，可在浏览器打印或另存为 PDF，并为 A4 分页设置表头。文件保留已发布账单编号、企业、月份、人民币收费分类与已扣总额、投放展示/点击及活动状态依据、账单说明和发布时间。发布时间按 America/Vancouver 展示，投放日期继续使用广告账户时区。

金额使用整数分格式化，不经 JavaScript 浮点换算；下载前校验两项收费之和等于已扣总额。页面和下载使用显式白名单数据结构，去除未知字段及嵌套未知字段，不将原始 API 响应、上游 CAD 成本、汇率、报价或内部核实依据加入客户数据。异常账单响应显示不可用，不提供下载或将其显示为零。

文件说明已从预付账户扣款、勿重复支付，并区分结算记录与税务发票。下载在客户已获授权且加载的账单上本地生成，不触发发布、支付、余额修改或对外发送。已经下载的文件不会因在线权限撤销而被远程删除，也不自动更新。

月结工作台在已发布阶段为管理员提供对应企业的客户权限核查入口；发布不自动授予客户成员或财务权限。客户页面为空时提示核查授权，不据此认定没有费用。本轮不需要数据库迁移。

验证覆盖：实际数据库发布结果与客户白名单结构兼容、成员及财务权限撤销后查询不可见、私有字段剔除、金额精度、CSV/HTML 注入防护、下载文件命名、错误提示；以虚构账单验证 Chromium 渲染和 A4 PDF 打印。数据库升级测试使用固定历史迁移起点，避免当前完整 bootstrap 更新后重复创建同一表。

031 新增客户主动查阅确认，见 [CLIENT_STATEMENT_READ_RECEIPTS.md](CLIENT_STATEMENT_READ_RECEIPTS.md)。查看和下载本身不自动生成已阅状态；已有报告金额和下载内容不因查阅确认而变化。
