# 报价与月结往返

沿用001–036，无新增 SQL 或审批。

- 从月结进入报价后，顶部提供所选企业/月的月结及结算入口。
- 已保存报价列表提供可清空的月份筛选，提交筛选时不会丢失所选月份。
- 每个版本的重新编辑入口使用该版本自身的企业及月份；不会把其他月份版本套入当前月份。
- 保存成功后的列表入口及返回月结入口使用实际保存的企业和月份，而非进入页面时的旧参数。
- 在列表切换企业时不保留旧 binding。账户级来源需重新从该企业月结工作台选择。
- 原报价保存、独立复核与发布规则保持不变；导航不会自动制单或扣款。

相关测试覆盖中英文往返链接、列表月份参数、按版本月份重新编辑、非法月份拦截及保存后的实际月份链接。真实授权账号仍需在 Preview 验收。

验证结果：16项报价UI、页面往返、保存API和归档API测试通过，Next.js构建通过。Chromium验证中英文报价页对未登录访问仍跳转员工登录；没有用真实账号执行报价保存或发布。
