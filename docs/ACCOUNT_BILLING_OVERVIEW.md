# Account billing overview — Preview

Top of statements/review now shows full-history account summaries independent of the viewing month, followed by the current task and the existing recent history. `058_account_billing_overview.sql` adds a read-only finance-scoped RPC. Apply only this migration after 057 in the existing Preview project, not the new-project bootstrap.

For each linked advertiser it reads actual automation settings, recorded first month, latest published consumption month, earliest missing closed month, current task and relevant workflow state. Closed months use the verified advertiser timezone. A missing first month is unknown, never inferred from a draft. Missing periods are detected before advancing beyond later publications. Unknown metadata, read failures, suspended bindings, retry/failed tasks and archived/rejected/source issues stay distinct. Publication/ledger posting is not bank payment verification.

Draft/coverage actions reuse `get_month_close_overview` and `closeAction`, including independent reviewer restrictions. Automatic accounts normally link to progress; manual accounts link to their next workflow step. Existing drafts are reused, with no new mutations on page view. History remains a maximum of 50 drafts under the existing selected company/month; account summary is not limited by those 50 records.
