# 广告金额展示和客户表现指标

2026-11-15，Preview 展示更新。无 SQL、无业务写入、无邮件或弹窗。

## 当前客户展示

用户决定客户不展示 CPC/CPM。客户账单页面、HTML/PDF、CSV 和原有客户月报只展示展示次数、点击次数和 CTR，不输出 CPC、CPM 或其成本公式。CTR＝点击次数 / 展示次数 ×100%，末尾四舍五入两位；例如1017次展示、20次点击，CTR为1.97%。展示为零时显示“—”。原有客户月报明细缺失或金额未核对一致时不计算 CTR。无需扩展客户投影、披露内部采购成本或改写已发布账单。

## 内部广告表现

内部来源页面及其 PDF/CSV 保留 CPC、CPM：使用已取得每日原币广告花费 / 点击次数，以及该花费 / 展示次数 ×1000。缺少每日数据时不声称覆盖完整期间。原币36.24、1017展示、20点击，CPC1.81、CPM35.63。点击或展示为零时对应成本显示“—”。不把内部来源文件改成客户结算文件。

## 金额与密码显示

页面、可打印报告及来源 CSV 的广告金额按原始整数精度汇总后四舍五入显示两位。原始快照、API 返回和用于核实的提交值保持六位精度；显示值不用于反向计费或核对。逐行显示舍入后与合计可能有尾差。

登录、密码重设和账号初始密码使用共享眼睛按钮。默认隐藏，点击不提交表单，保留输入值和自动填充属性。不改变登录权限、验证器或密码存储方式。
