# 广告金额展示和客户表现指标

2026-11-15，Preview 展示更新。无 SQL、无业务写入、无邮件或弹窗。

- 页面、可打印报告及来源 CSV 的广告金额按原始整数精度汇总后四舍五入显示两位。原始快照、API 返回和用于核实的提交值保持六位精度；显示值不用于反向计费或核对。逐行显示舍入后与合计可能有尾差。
- 内部来源页面及其 PDF/CSV：CPC 使用已取得每日原币广告花费 / 点击次数；CPM 使用该花费 / 展示次数 ×1000；缺少每日数据时不声称覆盖完整期间。不把来源 CSV/PDF 改成客户结算文件。
- 新月度客户账单页面及 PDF/CSV：使用客户可见的人民币“广告与执行服务”金额计算 CPC/CPM，明确含执行服务、不含运营及其他费用。无需扩展客户投影来公开内部采购、汇率或利润。示例：211.98元、1017展示、20点击 → CTR1.97%、CPC10.60元、CPM208.44元。此口径与内部CAD原始成本口径不同，不标为纯平台媒体成本。
- 原有客户月报 ReportDocument：按月报币种的广告费用计算，不含另列服务费。明细金额未核对一致、展示/点击缺失时不计算成本指标。原币36.24、1017展示、20点击 → CPC1.81、CPM35.63。报告语言切换和PDF打印均保留这些信息。
- 点击为零时 CPC 为“—”，展示为零时 CTR/CPM 为“—”。所有指标使用 BigInt 分数计算，末尾才舍入；不先四舍五入花费再计算。
- 登录、密码重设和账号初始密码采用共享可访问的眼睛按钮。默认隐藏，点击不会提交表单，保留输入值和自动填充属性。没有密码持久化、登录权限或验证器流程变化。
