# 管理员全流程自动化自查

日期：2026-11-26（America/Vancouver）。范围：管理员五个模块的页面、API、数据库函数、授权及现有任务。此轮为代码与规则审查，未登录托管管理员界面逐项操作；未改动业务代码、配置、权限、数据库、定时任务或 Production。托管证据来自会话：Preview 月结单次后台调用 prepared，Kenny/REMAX 10月 CAD36.24 → CNY248.33 已核算；每日 cron 已安装，尚未取得到点自动执行及完整独立复核发布的验收证据。

## 统一目标

规则、归属、收费和授权完成一次真实确认后，系统自动完成后续可确定步骤。自动计算、确认后联动和无人值守任务分别标识，不能把有计算按钮当成已配置定时自动化。正常步骤保留记录，失败/缺少依据/金额差异才进入待处理；查询、切换页签、查看记录不产生业务写入。管理员授权、客户确认、独立财务复核和实际收付款核验仍用各自真实动作，不能根据推测写成已完成。

## UI 建议

保留五个业务模块和已有角色守卫。每个模块按内容需要采用三个工作区：

1. 自动处理：已上线规则、连接/启用状态、处理结果与异常，不为尚未实现的能力放一个假的启用开关。
2. 待确认与手动办理：真实确认、特殊约定、补正、退回、人工接管。进入此区不自动暂停任务或重跑业务。
3. 记录与查询：同一套企业/账户/单据历史与审计，不建立独立的自动/手动账本。

具体可命名为：客户开通/人工审核/客户记录；自动同步/手动接入与补正/来源记录；既有自动月结/手动办理/账单与复核；自动计佣/审核与付款/结算记录；开通检查/授权办理/账号记录。名称和可见性按角色与真实实现决定，不强迫每个模块存在三份空页面。自动模块仅显示已上线功能，拟开发的放在文档中。

工作总览优先显示“需要我确认”“异常待处理”，自动成功记录可折叠。现有 HomeAttention 是基于业务记录读取/计算待办，不等于已发送邮件、微信或后台推送。本轮未授权外部通知发送。

## 实施优先级及验收

P0 多账户连接：保留 Kenny 现有连接，新增 Brianna 独立路由，验证身份、币种/时区、零消费/缺失覆盖、多客户隔离、失败互不影响、定时到点执行；未具备实际凭证/数据不能声称连接通过。

P1 客户开通串联：首次确认后自动复用客户资料和生成待办/配置草稿，复用现有转换和申请审核能力，不另造重复企业；重试不重复建企业/账号/绑定；不能扩大权限。

P2 佣金自动草稿：在已发布且实际到账支持、归属有效、退款不暂停的条件下计佣，按账单去重；检查等待期和重复结算，保持独立复核及线下付款边界。

P3 收付对账候选与工作台：在已保存、可核实的记录上给出候选匹配；真正自动确认到账需未来独立银行/支付通道和明确规则。工作台按现有后台能力分区，不把 UI 调整冒充新自动化。

以上为待实施建议，不自动启用新流程。当前默认自动只适用于已有真实授权、有效规则、连接就绪和数据核实通过的范围；条件不满足时显示明确待办原因，不静默默认、补零、覆盖或自动重试未知资金/身份写入。
