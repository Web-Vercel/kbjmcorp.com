# 内部报价草稿快照（018）

## 开通

独立测试库整份执行 `supabase/migrations/018_agency_quote_snapshots.sql` 一次，建议保存“14 内部报价草稿版本与权限—已执行”。新增草稿表、管理员保存函数和财务结果投影函数，不变动余额、已发布月报或收费规则。

最新 Preview 管理员访问 `/zh/operations/pricing`。先选企业、报价月份（年／月，系统自动保存为当月1日）并填写报价说明／手动汇率依据；配置收费规则和跨境成本后试算，再明确点击“保存内部报价草稿（不生效）”。试算本身仍不保存。成功会显示记录编号和查看版本入口，失败不显示已保存。修改输入后必须重新试算。

## 快照

保存冻结本次输入规则、计算版本、原始广告费、汇率来源及日期、加拿大服务费、中国服务费、成本承担方（含公司承担时的加拿大／中国归属）、跨境成本计算方式、各项计算结果和管理员说明。规则为本次输入副本，不假装已经关联到正式生效收费协议；修改后的新版本不改变旧快照。

服务器验证格式、精确重算费用并生成请求指纹，不接受浏览器伪造总额、创建人或批准状态。自动参考汇率再次从固定来源验证，若与试算日期或数值不同返回409，不静默保存另一价格；查询失败返回不可用，不降级为手动来源。保存央行序列、原始CNY/CAD值和日期作为来源证明；数据库创建时间记录保存时间。该接口在开发环境的真实网络访问仍未通过，手动试算保存可独立验收。

相同管理员、相同requestId和相同请求重试返回原记录，不追加审计或版本；改变同一请求内容返回冲突。新试算使用新requestId，按企业和月份递增版本。采用请求级与企业级事务锁、唯一约束和不可修改／删除触发器保护历史。

## 权限

原始快照表仅active admin + MFA可读，管理员才可保存。财务通过 `get_agency_quote_results` 在授权企业范围内读取最近20条记录的编号、月份、版本、草稿状态、CNY总额和创建时间，不返回汇率、供应商成本、备注或私有规则。普通客户不能读取内部报价结果。

此处为草稿而非财务凭证。管理员有权直接通过数据库管理工具写入草稿，这不构成银行核实、平台原件校验或客户接受证明。进入正式报价／扣费流程前必须重新验证来源、收费协议与证据并独立复核；不能直接把草稿JSON当作可扣款指令。

## 验收

管理员用虚构测试企业保存手动报价，刷新后相同编号与金额可见；改变方案后重算另存新版本。财务账号只能查看CNY总额，不能展开内部汇率；直接查询快照表应无记录。重试同一请求不增加版本；错误自动汇率或失效权限不能保存。全程不收款、不换汇、不生成应收应付、不扣客户余额。

后续增加报价确认、独立审核、生效版本与原始报告绑定，再开发正式账单与公司间结算。合同原件仍在线下受控档案保存。
