# 运营菜单与制单职责核查

2026-11-15，Preview。此前运营首页菜单按职责筛选，右上角 BusinessNavigation 却枚举全体运营路径。页面有权限限制，但菜单仍显示不适用入口。本次仅将已验证的 OpsContext 从服务端布局传入主菜单，按现有页面能力筛选；不增加业务权限，不改 SQL。

## 中国财务制单账号

| 入口 | 应显示 | 职责边界 |
|---|---|---|
| 月结工作台、月度结算制单与复核 | 是 | 核对来源、准备月结草稿；不可独立复核、批准或发布正式账单 |
| 广告来源资料、整月活动覆盖核实 | 是 | 查看获授权来源、提交核实依据；复核由另一有权限账号完成 |
| 报价查看 | 是 | 查看已授权报价结果；编辑、归档、汇率与内部成本仍仅管理员 |
| 对公收款与入账 | 是 | 登记到账依据，提交独立核实；原收款测试范围限制继续生效 |
| 客户资金对账、入账资金摘要 | 是 | 只读核对余额和流水，不直接编辑余额 |
| 公司间到账核对 | 是 | 登记已在线下发生的到账与分配；不可自行独立复核，不发起汇款 |
| 代理业务 | 是 | 准备佣金、扣减及结算、登记已批准的线下付款；代理账号及归属管理仅管理员 |
| 客户余额退款 | 是 | 核算、退回资料不足申请、登记已批准的线下付款；复核和批准分别授权 |
| 服务工单、账单问题跟进 | 是 | 按现有可读企业与类别跟进；回复不自动改变余额或收费 |
| 手工报表交接、手工核对草稿 | 是 | 查看手工来源/草稿、按已有权限退回来源；不因财务角色获得加拿大来源提交权；旧手工草稿生成功能仍管理员专用 |
| 手工关联广告账户 | 否 | 管理员或加拿大投放执行职责 |
| 人员职责 | 否 | 管理员 |
| 广告数据同步 | 否 | 管理员读取 API 和配置归属 |
| 公司间采购对账 | 否 | 管理员查看采购、内部成本构成 |

## 其他角色

复核角色与制单角色可进入同一批财务工作区，但页面内操作分别由 canPrepare/canReview 及独立复核规则约束。管理员保留全部运营入口；加拿大投放执行仅来源相关入口；客服仅服务入口。未能取得运营权限时，仅保留工作台根入口，不猜测或默认显示全部菜单。直接访问隐藏路径仍由原服务端页面/API/RPC 检查，隐藏菜单不是授权机制。

验证覆盖角色主菜单、管理员保留入口、未验证权限、加拿大来源/中国客服区别，以及报价只读、采购页面限制、广告同步限制、制单直访人员职责和关联账户的拒绝行为。
