# 公司间CAD核销汇总与报告

沿用001–036，不新增SQL、审批或银行接口。位置在 `/zh/operations/upstream-payments`（公司间到账核对与核销），管理员或获授权财务按企业与采购账单月份查询后可查看汇总、下载内部CSV。

## 汇总与口径

显示该月已发布采购额、已独立复核核销、尚未核销、待复核分配及待复核撤销批次。只计CAD，不混入人民币客户余额。已复核核销排除被批准整笔撤销的历史分配；待复核撤销尚未生效，仍保留原已核销金额。待复核到账分配不算已核销、不预留采购额。

最重要的是月份按采购账单，而不是银行到账日期。一笔登记净到账CAD130，分配一月CAD80、二月CAD50时，一月已核销只计CAD80，不计整笔CAD130。报告分成三个区段：

- 本月采购账单：每张账单采购/已核销/未核销/待复核金额。
- 涉及本月的到账登记批次：每个登记版本仅一行，列银行参考号、登记整笔净到账、本月分配、其他月份分配、复核和撤销状态、登记/复核时间。
- 本月逐笔分配：只列本月账单分配及实际计入已核销/待复核的金额，不复制其他月份的账单编号或账户详情。

登记批次保留退回与撤销历史；不同版本不是新的银行付款，不可把“登记整笔净到账”列相加当作本月付款。本报告不代表银行原件、客户账单、客户接受收费或整体业务结清，不发起汇款、不再次扣客户余额。原页面每张采购账单增加同企业/月的原结算账单链接，便于回查。

## 数据与访问

沿用现有 `get_upstream_payment_workbench` 的企业/MFA财务权限和完整记录计数。只有全部200张以内账单及100笔以内登记均取得，才对采购与分配进行整体验证；包括唯一编号、月份、整笔金额等于全部分配、当月分配有对应账单、逐账单有效核销/待复核金额一致及核销不超采购额。记录截断、查询失败或金额矛盾时不显示推测合计、不导出部分文件，原已取得记录仍按原页面展示。

服务器把最小报告对象投影后交给下载组件。不输出银行原件依据、文件哈希、说明、工单正文、员工身份、内部汇率或广告原始成本。**银行参考号特意保留**，用于内部财务对照银行记录；此文件仅交给获授权内部财务，不交付客户。客户仍用客户门户正式账单与资金对账单。

没有正式采购账单时明确说明暂无明细且不提供空报告下载，不把它解释成广告费用为零；有已发布零采购额账单时保留真实账单编号及零金额。文件含生成时间，是查询时点记录，不会自动更新。

## 验证

纯函数测试包含跨月整笔130/本月80/其他50、待复核10、退回20、已撤销历史30，确认本月只核销80；校验截断、错误月份、金额不等、原件和身份剥离、CSV公式注入防护。按钮仅点击下载，不自动发起API写入；金额未知时不显示假零或导出。

隔离PGlite实测原CAD110核销：撤销申请待复核仍显示已核销110，批准撤销后显示已核销0、未核销110，并保留原版本；整个过程客户CNY余额及流水数量不变。页面测试验证财务权限、原结算链接和记录不完整时保留原列表。所有资料均为虚构，不修改预览客户或真实银行数据。

Preview部署后刷新“公司间到账核对与核销”即可，无需SQL。只登记真实已在线下发生的到账；不为完成汇总而制作虚构付款。
