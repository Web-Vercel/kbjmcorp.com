# 制单条件提示与补齐入口

沿用001–036，无新增 SQL、审批或查询。入口为原 `/zh/operations/settlements`，仅在已有制单权限的表单内提供提示。

- 成功读取但没有已交接来源时，提示核查归属、整月读取和交接；不认定为零花费。
- 已有来源但不适用时，逐份说明非完整自然月、非 CAD、来源差异或汇总/活动覆盖待核实。原 sourceReady 判断保持不变；不放宽制单条件。
- 来源补齐入口保留所选企业和月份。需要新增报价时使用所选来源自己的月份，避免跨月最近记录视图把报价导向错误月份。
- 非管理员提示报价由管理员维护；链接只是读取/导航，不授予写权限。同月报价候选不代表成本已匹配或客户已同意，服务器继续核对成本与版本状态。
- 切换月份时重新挂载制单表单，清除上一月份的来源选择。
- 来源查询失败仍显示原错误，不伪装成无数据。未核实来源不提供制单按钮，确认框不自动勾选。

验证使用虚构来源：空交接、部分月份、非 CAD、差异、核实零活动、候选月份过滤、定向报价链接及查询错误。真实 Preview 仍需获授权人员登录验收；本项不操作真实资金、报价或账单。

验证结果：14项来源制单UI、制单API及结算页面测试通过，类型检查及Next.js构建通过。Chromium验证中英文结算页仍要求员工登录；未使用真实账号执行制单、复核或发布。
