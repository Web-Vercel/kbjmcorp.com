## 已实施

- 制单员/复核员主菜单15项收敛为8项：问题中心、来源核对、月结办理、收款登记/复核、资金查询、退款办理、公司间对账、代理佣金与结算。具体角色动作名称继续显示。
- 管理员运营主入口19项合为11项；CRM/项目/广告账户/权限管理入口保留。工作总览快捷入口同步合并，避免首页仍出现旧的重复任务列表。
- 月结办理：进度、制单与复核、收费报价。
- 来源核对：同步来源、完整性核对、手工报表、手工草稿与复核。执行职责只能看到获准的手工报表入口；内部汇率不提供给财务复核员或执行人员。
- 资金查询：余额流水、月度摘要；公司间对账：到账核销、采购账单（管理员）；问题中心：账单问题、服务与财务咨询。
- 原路由继续可用。选择区内环节时只传递企业和月份，不携带工单、报价编辑目标、凭证等无关参数。旧详情链接正确高亮统一侧栏；面包屑显示所属办理区。手机导航可换行。
- 手工报表按传入企业/月筛选，提交表单带入企业/月但不默认选择广告账户；手工核对草稿也按来源企业/月筛选。仅展示服务器已授权记录，不替代服务端权限。
