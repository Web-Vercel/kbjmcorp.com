# 内部月结办理清单导出

本功能沿用001–036，无新增SQL迁移或审批。财务/管理员在 `/zh/operations/month-close` 选择企业和月份后，点击“下载内部月结办理清单（CSV）”；英文页面提供对应按钮。

## 内容与用途

用于内部财务办理交接和下载留档，保留当前待处理状态，不是客户账单、税务发票、银行凭证、客户同意收费或业务结清证明。点击只在浏览器生成文件，不自动读取广告API、不审批、不扣款、不汇款、不写已阅、不保存新的数据库快照。

文件记录企业、结算月份、生成时间，以及：

- 查询时点人民币资金账户、已入账余额和待复核到账。此余额不是月末余额，未为草稿预留；待复核金额不计入余额。
- 每个广告账户当前办理阶段、来源编号和核实依据状态、草稿编号与金额、正式账单编号、已发布扣款及发布时间。
- 已发布账单的客户查阅确认数量及最近时间；不把已读当作接受收费。
- 对应账单的CAD采购额、已复核核销、待复核分配，以及是否有待复核撤销；公司间核销不再次扣客户余额。
- 本月账单关联问题的完整状态汇总；一般未关联账单工单不计入，已处理不代表客户同意。

CNY与CAD分列，不相加。未发布账户的正式账单、查阅和核销字段留空，不推断零费用或结清。所有行保留来源、草稿及账单编号供回原记录核对。

## 数据完整性与隐私

在服务器投影出专用导出对象后，才传给浏览器。排除CRM电话提示、成员/员工身份、银行参考号、原件依据及哈希、退款/撤销说明、问题正文、内部汇率及收费规则、CAD原始广告成本等；只保留财务已有权限的上述办理字段和采购核销合计。该文件供内部使用，客户交付仍使用客户门户的正式账单和资金对账单。

校验所选企业/月匹配、账户归属编号和正式账单编号不重复、已发布与未发布字段一致、草稿及正式金额一致。存在已发布账单时，要求查阅及核销查询完整且编号/月匹配；核销汇总与逐笔分配不符、超过原200份账单/100笔记录上限、查阅超过200条、返回计数与详情不符或关键模块失败时，暂停导出。账户超过1000条亦暂停，不制作截断文件。账单问题只导出完整汇总，允许其历史明细列表截断，因为不导出该列表。

没有发布账单时，查阅和核销字段属于“不适用”，无需伪造查询记录，也可导出真实待处理阶段。没有关联账户、没有取得所选企业的有效数据时不导出。未开户明确写尚未开户，资金字段留空。

这是页面多个模块查询结果的留存副本，不宣称单个数据库事务的一致快照。并发入账、回复或复核可能使查询先后有所不同；原始账单、流水和复核记录为准。清单显示生成时间，下载后不自动更新，也不锁定该月。

## 验证

纯函数测试验证大于JS安全整数的金额字符串精度、CSV公式注入保护、私密字段不传到浏览器、企业/月匹配、缺失/截断/矛盾资料暂停导出、未发布与未开户字段留空。按钮测试验证仅点击下载、不自动操作、文件名含企业与月份；月结页面测试验证关键数据失败时禁用导出。

隔离PGlite主流程案例的真实SQL查询结果也经过清单构造：客户CNY605扣款、余额CNY395、CAD110核销及1条待处理问题，原资金仍只有三条流水。均为虚构验收数据，不代表真实银行或广告账户验收。

Preview部署完成后，管理员或授权财务可直接刷新月结工作台，无需再执行SQL。未完成月结也可下载清单交接，不必为让清单显示已完成而创建虚构付款或客户确认。

清单现包含当前已复核待发布草稿数量/合计、覆盖这些草稿的资金缺口及未纳入的其他账户数量，具体口径见 [MONTH_CLOSE_FUNDING_COVERAGE.md](MONTH_CLOSE_FUNDING_COVERAGE.md)。未开户或没有本次待发布草稿时，缺口字段留空，不推断为零；待核对到账不抵消缺口。
