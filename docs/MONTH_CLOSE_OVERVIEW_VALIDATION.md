# 月结工作台数据核对

沿用001–037，无新增SQL或审批。只影响内部月结工作台，不改变正式首页、账单、资金或原数据库权限。

工作台在显示任何账户进度、金额、角色待办或正式账单交接之前，先核对接口返回的企业和月份与当前选择一致，并验证阶段、金额字符串、编号、时间、布尔标志和计数格式。保留大整数金额字符串，不转浮点。绑定、广告账户、草稿和正式账单不能在不同账户行重复。发布阶段须有账单编号、发布时间、匹配的草稿/已扣金额；来源已具备须有来源编号。

查询失败、空返回或校验不通过时，暂停显示该次月结数据及办理入口，给出刷新及请管理员核查提示；不推断零费用、余额充足或已经结清。不会继续查询客户成员、查阅回执或核销详情。不自动重试、批准或扣款。账单问题查询仍为原独立只读请求。

原SQL在已发布账户暂停交接时仍保留发布回执、隐藏来源信息，新校验允许这种合法历史状态；未开户、无账户及未准备来源也可正常显示。最新状态仍以重新查询及原记录为准，页面不是事务快照。

验证：32项测试覆盖页面、校验、角色待办、主流程及加载001–037的隔离PGlite贯穿案例。贯穿案例各次查询均经过新解析器，验证正常到账、来源、制单、复核、发布及核销数据兼容；没有访问真实广告接口或写入真实客户数据。
