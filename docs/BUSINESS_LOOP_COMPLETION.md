# OpenAI广告业务闭环：开发完成与真实验收边界

2026-11-10（温哥华）。这是当前结论入口；早期阶段文档保留作为历史记录，不再作为当前功能清单。

## 开发结论

当前约定的核心商业模式在代码及隔离数据库中已闭环：

客户建档与授权 → 人民币对公预付款登记 → 实际到账制单及另一账号独立复核入账 → OpenAI广告账户只读数据读取 → 客户归属及指定来源交接 → 整月活动范围核实（含部分天活动和零活动） → KBJM加拿大与中国智点未来分别收费、锁定内部汇率及跨境成本 → 月结制单及独立复核 → 管理员正式发布并原子扣余额 → 客户查看、CSV下载、查阅确认及账单问题跟进 → 公司间CAD实际到账、独立复核核销及可追溯纠正。

数据缺失不是零使用，报价不是客户接受，内部交接不是客户授权，制单和复核不是发布，CAD核销不再次扣人民币客户余额。两家公司独立核算，服务费收入不等于净利润。

本轮不再新增财务审批，补齐工作台和内部CSV的统一闭环判断：

| 显示 | 含义 |
| --- | --- |
| 本月仍有业务待办 | 尚未全部发布、客户尚未确认查阅、采购未全部核销或有待复核分配/撤销 |
| 主流程已贯通，账单问题仍待跟进 | 全部账单、查阅及公司间核销具备，但仍有新建/处理中的账单问题 |
| 本月系统记录已闭环 | 本页完整账户全部发布，客户均提交查阅确认，采购均核销且无待核销复核，关联账单问题无待处理 |
| 闭环状态待核实 | 查询失败、缺少记录、范围不符或关联数据不完整，不推断完成或零费用 |

判断覆盖当前企业/月的全部账户，不受账户列表筛选影响。新收款待复核不冒充已入账，也不会单独把已经结算的月份变成未结；未关联账单的一般工单不计入该月判断。客户追问可重开、核销可受控撤销，之后重新查询会恢复待办。此判断是查询结果，不锁账、不开具结清证明、不取代银行和合同原件，不是新增关账审批。

## 一次性真实办理验收

入口：`/zh/operations/month-close`。选定正确企业和已结束月份，按同一范围贯穿以下步骤。

1. 管理员核实真实企业、广告账户归属、客户成员及财务查看权限，开立人民币账户并核对收款配置。虚构企业验收模式不能用于真实客户资金登记。
2. 制单人员依据真实对公到账原件登记；另一账号独立核对入账。未核对的付款通知和到账不能用于发布余额。
3. 管理员读取该自然月完整范围并交接指定来源。只有一两天活动也可结算；未提供逐日行不能直接补零。对汇总、指标及范围进行自动或有依据的独立核实。
4. 按实际收费约定保存加拿大和中国两层报价及内部汇率/跨境成本。报价成本须匹配该月来源；内部汇率及采购利润不能填入客户可见说明。
5. 财务制单，另一账号复核，管理员核对正式说明与资金后发布。余额不足不发布，同一广告账户月份不能重复扣款。回执和原记录用于核查未知结果，不另建同内容付款。
6. 客户本人登录查看正式账单、下载并提交查阅确认。查阅不是同意收费；收费约定应在制单前已有依据。
7. 账单疑问通过原账单关联工单处理，客户追问会重开。问题处理不自行修改已发布金额。
8. 仅在加拿大已实际收到中国公司的CAD款项后，登记并分配到正式采购账单，另一账号复核。核销错误按原记录申请整笔撤销并登记修正版，历史保留；不代表银行退款。
9. 工作台显示“本月系统记录已闭环”，下载内部CSV，并与原账单/钱包流水/采购/银行原件核对。下载不自动改变任何状态。

## 尚未代办或不在本次核心范围

- 真实银行凭证、实际收费约定、客户本人登录和不同人员复核，必须由获授权业务人员完成，不能为让进度变绿而虚构。
- 线上Preview部署状态受环境网络限制，不能把Git推送或本地构建当作线上通过。Production发布未授权，本轮未发布。
- Ads读取目前由管理员触发。无人值守定时同步、自动发布/扣款不是已交付能力；核心闭环保留人工核实与发布。真实接口仍以广告平台已开放权限为准。
- 银行自动汇款/退款、税务发票/总账系统、电子签章不在当前闭环范围。
- Google Ads、Meta Ads、TikTok Ads只有已授权的业务展示，API运营能力须后续逐平台评估，不属于OpenAI当前闭环完成声明。
