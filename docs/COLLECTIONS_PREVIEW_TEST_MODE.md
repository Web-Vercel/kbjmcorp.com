# Preview 虚构财务测试模式

仅在现有隔离测试项目的 Vercel Preview 配置 `COLLECTIONS_TEST_ORGANIZATION_ID` 为专用企业 UUID。企业名称必须准确为“财务流程验收企业（虚构）”，且已开立 CNY 钱包。Production 永不激活该模式。未配置时保持原真实核实流程；错误 UUID 配置会停止页面加载，不应继续填真实表单。

重新部署最新 preview/tenant-isolation，使用新 Preview 地址，将域名加入 Turnstile。访问 `/zh/operations/collections`，必须看到“虚构财务流程验收”和不可付款提示，再进行操作。旧的固定部署网址不会更新。

服务器强制测试收款身份与不可付款账号 TEST-NOT-PAYABLE-001，依据编号 FICTIONAL-TEST-ONLY-001；绑定、制单和复核验证专用企业钱包及测试账户标记。页面只列出测试资料。客户付款通知可不关联。制单和审批仍调用现有真实数据库函数，要求真实登录、员工权限及 MFA，不能自审；审批产生持久测试流水，并非自动回滚。不要向任何银行付款。

这是一层应用验收限制，不是数据库或真实银行沙盒。现有员工角色仍有其数据库权限，不能声称该环境从数据库层隔离所有实际业务。仅用于没有正式客户资金的独立测试数据库，不应配置到承载正式资金的项目。不能直接把该测试账号改成真实收款主体。

账户和凭证沿用不可改写保护。测试结束停用测试收款指引，保留历史，移除 Preview 配置并重新部署；不删除已入账流水或把测试企业转为真实客户。停用配置不会清除数据或撤销员工会话。需要重做测试时使用新的明确标记测试钱包方案，不删除流水来归零。
